# ช่อชัยพฤกษ์เกมส์ ครั้งที่ 37 — เว็บตารางแข่งและผลสด

เว็บนี้ใช้ GitHub Pages เก็บหน้าเว็บ และใช้ Firebase เป็นฐานข้อมูลกับระบบล็อกอินครู
ผู้ชมทั่วไปเปิดดูได้ทันทีโดยไม่ต้องมีบัญชี

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ตารางแข่ง คะแนนสด จอแสดงผล เช็คชื่อ) |
| `firebase-config.js` | ค่าเชื่อมต่อ Firebase ต้องแก้ก่อนใช้งาน (ขั้นที่ 4) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล วางใน Firebase (ขั้นที่ 3) |
| `logo.png` | ตราโรงเรียน ใช้เป็นไอคอนเว็บ |
| `.nojekyll` | บอก GitHub Pages ให้ใช้ไฟล์ตามที่เป็น |

ห้ามใส่รายชื่อนักเรียนลงในโฟลเดอร์นี้ เพราะ GitHub แบบฟรีเปิดให้ทุกคนอ่านได้ รายชื่อนำเข้าผ่านหน้าเว็บหลังล็อกอินเป็นแอดมิน (ขั้นที่ 7)

---

## ขั้นที่ 1 สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com ด้วยบัญชี Google ของโรงเรียน
2. กด **Create a project** ตั้งชื่อ เช่น `chor37-games`
3. หน้า Google Analytics เลือกปิดได้ แล้วกดสร้าง

## ขั้นที่ 2 เปิดระบบล็อกอินและฐานข้อมูล

1. เมนูซ้าย **Build > Authentication** กด **Get started**
2. แท็บ **Sign-in method** เลือก **Email/Password** แล้วเปิด **Enable** กด Save
3. เมนูซ้าย **Build > Firestore Database** กด **Create database**
4. Location เลือก **asia-southeast1 (Singapore)** ใกล้ไทยที่สุด เปลี่ยนภายหลังไม่ได้
5. เลือก **Start in production mode**

## ขั้นที่ 3 วางกฎความปลอดภัย

1. ใน Firestore Database ไปแท็บ **Rules**
2. ลบข้อความเดิมทั้งหมด วางเนื้อหาจากไฟล์ `firestore.rules`
3. กด **Publish**

## ขั้นที่ 4 เอาค่าเชื่อมต่อมาใส่

1. กดรูปเฟือง **Project settings** มุมบนซ้าย
2. ส่วน **Your apps** กดไอคอน `</>` (Web) ตั้งชื่อแอป เช่น `chor37-web` ไม่ต้องติ๊ก Firebase Hosting
3. จะเห็นโค้ด `const firebaseConfig = { apiKey: ..., ... }`
4. คัดลอกค่าในวงเล็บปีกกา ไปแทนค่าตัวอย่างในไฟล์ `firebase-config.js`

ค่าเหล่านี้ไม่ใช่รหัสลับ ใส่ในเว็บสาธารณะได้ ความปลอดภัยมาจากกฎในขั้นที่ 3

## ขั้นที่ 5 ขึ้นเว็บบน GitHub Pages

1. สมัครหรือเข้าสู่ระบบ https://github.com
2. กด **New repository** ตั้งชื่อ เช่น `chor37` เลือก **Public**
3. กด **uploading an existing file** แล้วลากไฟล์ทั้ง 5 ไฟล์ในโฟลเดอร์นี้ขึ้นไป (`.nojekyll` เป็นไฟล์ซ่อน ถ้าลากไม่ได้ข้ามได้)
4. กด **Commit changes**
5. ไปที่ **Settings > Pages** ตรง Branch เลือก `main` และโฟลเดอร์ `/ (root)` กด Save
6. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อบัญชี.github.io/chor37/`

## ขั้นที่ 6 อนุญาตโดเมนให้ล็อกอินได้

1. Firebase **Authentication > Settings > Authorized domains**
2. กด **Add domain** ใส่ `ชื่อบัญชี.github.io` (ไม่ต้องมี https และชื่อ repo)

ถ้าข้ามขั้นนี้ ครูจะล็อกอินไม่ได้

## ขั้นที่ 7 ตั้งแอดมินคนแรก

1. เปิดเว็บ ไปแท็บ **ครู / ผู้ดูแล** กด **ลงทะเบียนครูใหม่** ใส่ชื่อ อีเมล รหัสผ่าน
2. กลับไป Firebase **Authentication > Users** คัดลอกค่า **User UID** ของบัญชีนั้น
3. ไป **Firestore Database > Data** กด **Start collection** ตั้งชื่อ `roles`
4. Document ID วาง UID ที่คัดลอกมา แล้วเพิ่ม 2 ช่อง:
   - `role` (string) = `admin`
   - `name` (string) = ชื่อที่จะแสดง เช่น `ครูนันทกร`
5. กด Save แล้วรีเฟรชหน้าเว็บ จะเห็นแท็บ **กรรมการสนาม** และ **เช็คการเข้าร่วม** และส่วนตั้งค่าของแอดมิน

ตั้งแอดมินผ่าน Firebase แค่ครั้งแรกครั้งเดียว ครูคนอื่นอนุมัติจากหน้าเว็บได้เลย

## ขั้นที่ 8 เตรียมก่อนวันแข่ง (ทำในหน้าเว็บ)

1. **นำเข้ารายชื่อนักเรียน:** ใน Google Sheets จัด 3 คอลัมน์ ชื่อ-สกุล | ห้อง (เช่น `1/1`) | สี แล้วคัดลอกทั้งหมดไปวางในช่อง **นำเข้ารายชื่อนักเรียน** แล้วกดนำเข้า
2. **อนุมัติครู:** ให้ครูลงทะเบียนเอง แล้วแอดมินเลือกสิทธิ์ **ครู** ที่ส่วน **จัดการบัญชีครู**
3. **ตรวจกติกา:** ปรับจำนวนเซตหรือแต้มที่ส่วน **กติกาการนับคะแนนสด** ให้ตรงกับระเบียบการแข่งขันของโรงเรียน
4. **ซ้อมใช้งาน:** ให้ครูลองนับคะแนนสด 1 นัด บันทึกผล แล้วกด **ลบผล**

## ค่าใช้จ่ายและโควตา

- แผนฟรีของ Firebase (Spark) อ่านข้อมูลได้วันละ 50,000 ครั้ง และเขียนได้วันละ 20,000 ครั้ง โควตารีเซ็ตเวลาประมาณ 14.00–15.00 น. ตามเวลาไทย
- ทุกครั้งที่คะแนนสดเปลี่ยน ผู้ชมทุกเครื่องที่เปิดหน้าเว็บอยู่จะใช้การอ่าน 1 ครั้ง ถ้ามีผู้ชมหลายร้อยเครื่องพร้อมกันระหว่างนับคะแนนสด อาจเกินโควตาฟรี และเมื่อเกินแล้วหน้าเว็บจะอ่านข้อมูลไม่ได้จนโควตารีเซ็ต
- แนะนำให้อัปเกรดเป็นแผน **Blaze** (จ่ายตามใช้) และตั้ง **Budget alert** เช่น 100 บาท ส่วนที่เกินโควตาฟรีคิดราว 0.03 ดอลลาร์ต่อการอ่าน 100,000 ครั้ง (ราคาภูมิภาค us-central1 ราคาสิงคโปร์อาจต่างเล็กน้อย) งานขนาดนี้น่าจะใช้ไม่เกินหลักสิบบาทต่อวัน
